## OpenAI Application Service for Workflow Efficiency

- Project Architecture: Microservice architecture, multi-model OpenAI SDK components, DDD-based application APIs, and a React web frontend
- Core Technologies: Spring Boot, MyBatis, OKHttp3, OpenAI models, React, and TypeScript
- Project Description: The project is split into microservices and covers OpenAI SDK integration, OpenAI API integration, and WeChat public account authentication. Its modular design allows different business scenarios to be connected in a configurable way.
- Key Responsibilities:
  - Designed the first stage of the OpenAI project with clear service boundaries so future integrations could scale through SDK access, HTTP APIs, MQ-based integration, and reusable service abstractions
  - Applied Domain-Driven Design to separate business domains and improve extensibility through models, repositories, events, and domain services
  - Added sensitive-word filtering to reduce the risk of unreliable or inappropriate content generated by large models
  - Built an independent SDK abstraction for different OpenAI models, using a session-based interaction model and factory-based service creation on top of OKHttp3
  - Applied abstraction, divide-and-conquer thinking, and design patterns throughout the system to keep the implementation maintainable
  - Planned future payment integration for product management, order creation, asynchronous fulfillment, and compensation for failed delivery scenarios
