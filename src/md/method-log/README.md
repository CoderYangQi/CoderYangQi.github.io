##  三维显微图像重构算法开发

- 项目架构：Python，PyQt开发，基于BSpline的FFD算法，自研算法
- 项目描述：
    - 生物样品透明化和染色的新方法可以产生大而透明的样品，并使用光学显微镜对样品快速成像。然而，获取到的单片图像数据量达到数TB，存在光学形变，且图像之间未对齐。本研究旨在开发一种大样品的三维图像重建算法，可有效拼接三维图像，解决切片图像之间非刚性形变的问题。
      重建算法流程包括：片内拼接、通道对齐、片间配准以及三维图像可视化。
    - 其中，片间配准计划使用的深度学习的检测器来提取出兴趣点和图像特征描述符，然后进行特征匹配并把特征点匹配关系扩展成三维图像的形变场；
    - 由于片内拼接、通道对齐的任务只需考虑位移误差，利用图像之间的相似性或者图像特征点集纠正偏移量。
    - 为了实用性，本研究基于PyQt设计了重建软件，该软件通过流程生成器产生多个子任务，任务调度器根据计算资源状态调度算法接口模块和数据读写模块来完成子任务，可以优化计算资源的分配，提高重建效率。该重建算法的研究将有助于获取高质量的三维荧光显微图像，进而可以更清楚、更全面地观察生物样品内的细胞和组织结构。另外，通过解决大样品重建中存在的技术问题，有望为其他生物医学图像处理领域提供新的方法和思路。
- 项目成果：
    - 开发了高效的三维重构算法工具，实现了对TB级图像数据的处理
    - 开发新的三维图像配准算法
    - 发明专利
